# RelayChat Naming Guide

## Product Name

- Official: `RelayChat`
- Short form: `RelayChat`
- Use as one word with capital `R` and `C`.

## Tagline

- `Local-first chat for communities, with decentralized sync and agent-native workflows.`

## One-Line Description

- `RelayChat is a decentralized, cross-platform chat platform with local-first data ownership and moderation-safe agent support.`

## Agent Naming

- Feature family name: `Relay Agents`
- Registry label: `Agent Registry`
- Public listing label: `Public Agent Directory`

## Style Rules

- Prefer `RelayChat` over generic references like `the app` in user-facing copy.
- Avoid legacy names (`Discord Replacement`) in docs, UI, and package metadata.
- Use `Relay Agents` when referring to the ecosystem, and singular `agent` for individual tools.

## Migration Note

- Existing local browser data may still use legacy storage keys. The app currently reads legacy key `discord_replacement_workspace_v1` and persists to `relaychat_workspace_v1`.
