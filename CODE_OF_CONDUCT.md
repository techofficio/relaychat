# Code of Conduct

## Our Standard

RelayChat contributors are expected to be respectful, constructive, and professional.

Examples of expected behavior:

- Using welcoming and inclusive language
- Respecting differing viewpoints and experiences
- Giving and receiving constructive feedback
- Prioritizing community safety and user privacy

Examples of unacceptable behavior:

- Harassment, discrimination, or personal attacks
- Public posting of private information without consent
- Bad-faith behavior that disrupts collaboration

## Enforcement

Project maintainers are responsible for clarifying standards and may remove or edit contributions that violate this code.

## Scope

This applies to project spaces and any public representation of the project.

## Reporting

For conduct issues, contact project maintainers through repository security/contact channels.
